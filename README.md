# Bridge SIPP Training

This repository contains a comprehensive set of Java practice programs and exercises, organized by topic and day. Each folder focuses on a specific area of Java programming, from fundamentals to advanced object-oriented concepts.

## Folder Overview

### Day 1. Practice Problem
- Beginner-level Java problems
- Arithmetic, conversions, area/volume, simple interest
- Designed to reinforce core programming concepts


### Day 2. Java Fundamentals
- Basics of Java programming
- Arithmetic operations, type conversions
- Simple interest, profit/loss, and unit conversions
- Swapping numbers, area and volume calculations
- Foundation for Java syntax and structure

### Day 3. Control flows
- For and while loops, conditional statements
- Number properties (Armstrong, Harshad, Abundant, Prime, etc.)
- Factorial, sum, product calculations
- Voting eligibility, leap year, FizzBuzz with loops
- Strengthens understanding of control flow in Java

### Day 4. Arrays
- Array operations and applications
- 2D to 1D conversion, FizzBuzz, BMI, grades
- Odd/even separation, multiplication tables, digit analysis
- Practice for array manipulation and logic



### Day 5. String
- String manipulation and operations
- Case conversion, substring, comparison
- Exception handling (null, index out of bounds)
- Word and vowel/consonant counting, games
- Mastery of string handling in Java

### Day 6. Method
- Solutions to Core Java practice problems (CP questions)
- Use of static methods for modular programming
- Covers simple interest, trigonometry, matrix, unit conversions, and more
- Reinforces method usage and modular design

### Day 7. Classes and Object
- Object-oriented programming (OOP) concepts
- Class and object creation, encapsulation, constructors
- Real-world analogies (Employee, Student, BankAccount, MovieTicket, etc.)
- Practice for inventory, shopping cart, palindrome checking, and more
- Deepens understanding of OOP principles in Java
